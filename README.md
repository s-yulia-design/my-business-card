# my-business-card

Одностраничная HTML-визитка для Селивановой Юлии: специалиста по созданию сайтов, ботов и digital-проектов с помощью ИИ.

## Просмотр

Откройте `index.html` в браузере. Страница не требует сборки или установки зависимостей.

## Состав

- `index.html` — готовая визитка с текстовыми блоками, контактами и адаптивной версткой.
- `assets/ai-specialist.svg` — изображение в футуристичном стиле для визуального блока визитки.
